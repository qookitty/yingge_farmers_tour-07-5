語音朗讀

台語（公開服務）

此服務由意傳科技提供，網站標示資源有限：同一 IP 一分鐘內最多下載 3 句音檔，單句約 25 秒；本頁會自動排隊等待。客語目前沒有「免費、免申請」的公開服務：客委會客語語音合成 API 需向維管單位申請並經核准，限政府機關、學校與公益團體，帳密不可轉授權或放在網頁裡。

進階：自備語音服務與逐站文稿

語音由你的瀏覽器與裝置提供，品質與可用語言因系統而異。瀏覽器不會提供「男聲／女聲」資料，本頁依語音名稱推測；找不到符合的語音時，會用音調近似，不保證像真人。背景播放受手機系統限制，無法保證在所有瀏覽器都不中斷。
